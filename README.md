# Animal Intake Analysis - Data Science Assignment

This repository contains a complete data science analysis and machine learning pipeline implemented in a Jupyter Notebook (`work2.ipynb`), focusing on regression, classification, error analysis, and critical reflections based on an animal intake dataset.


## Project Structure
* **Part 1 & 2 - Regression Models:** Comparison of Linear Regression, Decision Trees, and Random Forests for predicting continuous targets.
* **Part 3 - Classification Error Analysis:** 
  * Confusion Matrix & Error Interpretation (3.1)
  * Probability-Based Analysis & High-Confidence Errors (3.2)
  * Error as a Function of Features & Subpopulations (3.3)
  * Threshold Sensitivity Analysis, MCC, and ROC/AUC curves (3.4)
  * Comprehensive Discussion (3.5)
* **Part 4 - Final Reflection:** Critical insights, failure mode identification, and future improvements.

## How to Run
1. Clone the repository.
2. Ensure you have Python, Jupyter, pandas, scikit-learn, seaborn, and matplotlib installed.
3. Open `work2.ipynb` and run the cells sequentially.
